# Black-Body-Radiation-Simulator
This simulator calculates and plots the emission spectrum of a blackbody as a function of temperature. The user enters the temperature in Kelvin, and the system generates the spectral irradiance curve, identifies the emission peak (Wien’s Law), and calculates the total radiated power (Stefan–Boltzmann Law).

The main objective is to allow the user to visualize how the radiation distribution changes as the temperature of a black body varies.
